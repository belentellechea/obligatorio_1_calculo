## Descripción de archivos

| Archivo | Descripción |
|---|---|
| `parte1.py` | Verificación de convergencia de sumas inferiores y superiores |
| `parte2.py` | Análisis de influencia de distintos tipos de particiones |
| `parte3.py` | Comparación entre rectángulos, trapecio y punto medio |
| `parte4.py` | Implementación del método de Montecarlo |
| `utils.py` | Funciones auxiliares reutilizadas en el proyecto |


# Instalación de dependencias

Instalar NumPy:

```bash
pip install numpy
```

Instalar Matplotlib:

```bash
pip install matplotlib
```

Instalar Pandas:

```bash
pip install pandas
```

Instalar Tabulate:

```bash
pip install tabulate
```

O instalar todas juntas:

```bash
pip install numpy matplotlib pandas tabulate
```
